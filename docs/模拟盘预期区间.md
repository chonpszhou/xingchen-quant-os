## 解读

- 双低（收益型）：20 日持有中位数约 +1~2%，90 日约 +4~8%（年化 12-15% 对应）
- 双动量（趋势型）：波动更大，90 日区间明显更宽，出现 -5% 或 +15% 都属正常
- 风险平价（稳定型）：区间最窄，20 日通常 ±1% 内，回撤天然小
- 模拟盘累计收益持续落在 5-95% 之外 → 一致性监控会预警，需复核策略参数
