# 读懂模拟盘报告（小白版）

> 目标：让你不看代码也能看懂月报与风控状态，做出正确的“模拟转实盘”决策。

---

## 一、三个词先讲清楚

| 词 | 人话解释 |
|----|----------|
| **回测** | 用历史数据把策略“假装跑一遍”，看它过去表现如何。优点是快，缺点是历史不会重复 |
| **模拟盘** | 从今天起用真金白银的规则（但虚拟资金）实盘跟踪。它和回测的区别是：**接下来发生的每一天都是没见过的** |
| **基准** | 不操作策略、躺着买的对照物。跑赢基准 = 你的策略比“闭眼买”强 |

系统里三个模拟盘各有基准：双低 vs 全债等权、双动量 vs SPY、风险平价 vs SPY。

---

## 二、月报指标逐个人话翻译

| 指标 | 人话解释 | 怎么看 |
|------|----------|--------|
| 累计收益 | 从 100 万起至今赚/亏的百分比 | 正数正常，但别只看它 |
| 超额 | 策略收益 − 基准收益 | **核心指标**：连续为正才是真本事 |
| 最大回撤 | 从最高点最多亏了多少 | 双低 >20%、双动量 >25%、风险平价 >10% 就是超预期 |
| 月度胜率 | 赚钱的月份占比 | 55% 以上算稳健 |
| 盈亏比 | 赚的月平均 / 亏的月平均 | >1.3 说明赚的时候赚得多 |
| 调仓次数 | 换仓了几次 | 少而准最好 |

## 三、风控状态怎么读

每日摘要底部有风控栏：

- **✅ 正常**：回撤没到阈值的一半，放心持有
- **⚠️ 警戒**：回撤超过阈值一半，开始警惕，不加仓
- **🚨 超标**：回撤超过阈值，按纪律**暂停加仓并复核策略**（不是割肉，是停止投入新钱）
- **连续 3 个月跑输基准**：实盘资格受挫，暂停实盘计划，先找原因

## 四、实盘门槛（最重要的一页）

系统规定：**模拟盘连续 3 个月跑赢各自基准** 才有实盘资格。怎么自己判断：

1. 打开最近 3 份月报，看每个账户的“超额”列
2. 三份都是正 → 达到门槛，可以准备小资金实盘（先 1-2 万验证）
3. 有负 → 没达到，继续模拟，别急着上真钱

> 注意：即使达到门槛，也要先用小资金实盘 1-2 个月，确认实际成交和模拟一致（滑点/流动性差异），再逐步加仓。

## 五、常见误读（避坑）

1. **回测收益 ≠ 未来收益**：回测里双低年化 12-15%，不代表未来一定如此；模拟盘才是真实证据
2. **短期波动很正常**：刚开跑 1-2 周净值基本不动或小幅波动，不要因为“没赚钱”就怀疑系统
3. **别只看收益**：一个年化 20% 但回撤 40% 的策略，不如年化 12% 回撤 15% 的拿得住
4. **超额比绝对收益重要**：2026 年如果市场整体涨 10%，你的策略赚 8%，其实是跑输了
5. **预警必处理**：风控状态出现 🚨 不是“再看看”，是规则要求你行动
