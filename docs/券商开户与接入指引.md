# 券商开户与实盘接入指引

> 用途：为将来的实盘执行做准备。**当前系统保持模拟盘（paper）模式**，
> 切换实盘必须满足系统纪律：模拟盘满 90 天 + 连续 3 个月跑赢基准 + 回测-模拟一致。
> 本指引按 `config/broker.yaml` 逐项对照，照着填即可。

---

## 〇、总原则（先读）

1. 现在什么都不用开通，先让模拟盘跑满 90 天积累证据
2. 实盘切换顺序：**门槛达标 → 开户 → 填 broker.yaml → 改 active → 小资金验证 1-2 个月 → 逐步加仓**
3. 每家的凭证只填 `config/broker.yaml` 对应段落，系统其余代码零改动
4. 实盘前务必：先用 `python3 scripts/broker.py` 验证连接，再下第一笔真单

---

## 一、QMT（A股，可转债双低策略用）

适用：双低策略（A股可转债）实盘。

### 开户与开通步骤
1. 联系你的 A股 券商（华泰/国金/国盛等支持 QMT 的券商），申请开通 **QMT/迅投量化交易权限**（一般要求资产达标，需要签风险揭示书）
2. 券商提供：QMT 客户端安装包、**资金账号**、miniQMT 接口说明
3. 本机安装 QMT 客户端并登录一次（生成 userdata_mini 配置目录）

### broker.yaml 填法
```yaml
qmt:
  enabled: true
  account: "你的资金账号"
  path: "/Applications/QMT/userdata_mini"   # QMT 安装后的配置目录
```

### 验证
```bash
python3 scripts/broker.py    # 目前输出 paper 状态；接入后应显示 QMT 连接成功
```

## 二、富途 OpenD（港美股，双动量/风险平价 ETF 用）

适用：双动量（SPY/GLD/DBC）、风险平价（SPY/GLD/TLT/DBC）的美股 ETF 实盘。

### 开户与开通步骤
1. 注册富途证券并开通**美股交易权限**（大陆用户可开富途牛牛，需港股/美股账户）
2. 下载 **OpenD（开放接口网关）**：https://openapi.futunn.com/futu-api-doc/opend.html
3. 用富途牛牛扫码授权 OpenD（首次需要，授权后常驻运行）
4. 建议先用模拟环境（trd_env=SIMULATE）验证，再申请实盘权限

### broker.yaml 填法
```yaml
futu:
  enabled: true
  host: "127.0.0.1"
  port: 11111
  trd_env: "SIMULATE"      # 验证通过后再改 REAL
```

### 验证
```bash
python3 scripts/broker.py    # 接入后应显示富途 OpenD 连接成功
```

## 三、OKX（加密，预留）

适用：未来加密策略（当前三策略不含加密，先预留）。

### 开通步骤
1. 注册 OKX 并完成 KYC
2. 创建 API Key：**交易权限开最小集**（只开需要的，勿开提币权限）
3. 建议先用 **OKX 模拟盘（flag=1）** 验证，再切换实盘（flag=0）

### broker.yaml 填法
```yaml
okx:
  enabled: true
  api_key: "你的API Key"
  secret: "你的Secret"
  passphrase: "你的Passphrase"
  flag: "1"                # 0=实盘 1=模拟盘（OKX demo），先模拟后实盘
```

### 验证
```bash
python3 scripts/broker.py    # 接入后应显示 OKX 连接成功
```

## 四、实盘切换流程（90 天门槛达标后）

```text
1. 确认门槛：模拟盘连续 3 个月跑赢基准（看月报“超额”列全为正）+ 回测-模拟一致（看板「体检」）
2. 按上文开户并填好 broker.yaml 对应段
3. 把 active 从 "paper" 改为对应券商（如 "qmt"）
4. python3 scripts/broker.py 验证连接
5. 小资金（1-2 万）跑 1-2 个月，确认实际成交与模拟一致（滑点/流动性）
6. 一致后逐步加仓，全程观察看板风控与止盈止损是否自动生效
```

> 任何一步不对就先停在模拟盘，不要急。实盘的目的是验证，不是冒险。
