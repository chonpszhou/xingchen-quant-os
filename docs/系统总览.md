# 星辰投研团 · 量化交易操作系统 · 系统总览

> 版本：v3.0 · 更新：2026-08-11
> 定位：面向普通金融小白的量化交易操作系统——自动盯盘、自动信号、自动模拟盘、每日摘要。
> 目标对照与交付核查见 [交付清单.md](交付清单.md)。

---

## 一、系统定位与设计原则

本系统不是“荐股软件”，而是一套**有纪律的投研执行系统**：

1. **一切策略必须过统一门控**（事件研究/IC 为第一层证据，walk-forward 样本外含成本为最终门控）才能进入模拟盘
2. **模拟盘连续 3 个月跑赢基准** 才有实盘资格
3. **宁缺毋滥**：研究过 15+ 类策略，只有 1 个通过完整门控，1 个观察级，其余全部诚实归档
4. **数据与结论全部可复现**：13+ 份研究报告、全部脚本可重跑

## 二、架构分层

| 层 | 组件 | 说明 |
|----|------|------|
| 数据层 | `datahub/` + 抓取脚本 | A股 1119 / 港股 66 / 美股 65 / 加密 16 / 期货 10 / 可转债 1032 / 港股分红 54，多源自动降级 |
| 研究层 | `factors/` + research 脚本 | 因子评估 / walk-forward / DSR / 事件研究，统一门控 |
| 策略层 | 双低（实盘候选）+ 双动量（观察级）+ 风险平价（稳定型观察） | 均已回测、引擎一致性校验 |
| 执行层 | `scripts/broker.py` | PaperBroker 运行中；QMT/富途/OKX 实盘适配器即插即用 |
| 自动化层 | `scripts/run_all.py` + `config/tasks.yaml` | 每日全链路：更新→信号→双模拟盘→IV→期货→摘要→推送 |
| 知识层 | Obsidian `量化交易/` | 14 篇研究报告看板 + 用户手册 + 系统状态 + 学习笔记 |

## 五、如何使用（日常三条命令）

```bash
python3 scripts/run_all.py all        # 每日：更新数据→双低监控→双模拟盘→IV→期货→摘要
python3 scripts/run_all.py monthly    # 每月末：双账户月报（vs 各自基准）
python3 scripts/run_all.py status     # 随时：系统健康看板
```

### 一次性安装自动运行（macOS，可选但推荐）

```bash
python3 scripts/install_automation.py install
```

安装后系统全自动（launchd 常驻，日志在 `~/Library/Logs/星辰投研团/`）：工作日 16:35 全链路、每周日 20:00 周报、月末 17:30 月报。卸载：`python3 scripts/install_automation.py uninstall`。

## 六、验证状态

**已验证**：数据连通（25 项连接检查）、因子回测门控、模拟盘引擎与回测一致性（双低 0.00% 偏差 / 双动量 1.25% 偏差）、双低信用预警（实测命中 3 只 ST 风险券）。

**待时间验证**：两个模拟盘的月度跟踪（约 19 个交易日后首次调仓；连续 3 个月跑赢基准为实盘门槛）。

**待用户提供**：推送凭证（`.env`，填后自动启用邮件/IM）；实盘券商（`config/broker.yaml`，QMT/富途/OKX 任选）；Tushare token（可选，解锁分析师预期数据）。

**已完成**：日/周/月三级自动运行已安装（launchd 三个任务）；项目已推送 GitHub（main 分支）。

## 七、风险与纪律（务必阅读）

1. 模拟盘 ≠ 实盘：滑点、流动性、交易失败在纸面不可见，实盘前必须小资金验证
2. 免费数据有延迟与缺口（Yahoo 限流、东财部分地区不可达），系统自动降级但请以券商数据为准
3. 单一策略失效风险：双低 2023/2026 均有弱年，纪律是“回撤超阈值暂停加仓”，不是死扛
4. 只用闲钱，最大可承受亏损建议不超过总资产 20%
