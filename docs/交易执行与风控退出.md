# 交易执行与止盈止损（小白版）

> 说明：本系统“下单执行”在**纸面层已全自动**；接真实券商后同一套代码直接生效。

## 一、订单执行链路（全自动，无需手动）

```
行情/数据 → 策略信号 → 风控检查 → 生成订单 → 成交 → 持仓 → 退出规则 → 清仓
```

每个环节都由引擎自动完成：策略到调仓日自动出目标持仓，风控先拦（持仓数/权重/回撤熔断），
然后执行器按目标调仓（买入/卖出/记录流水）。你不需要手动下单。

## 二、止盈止损：自动，规则可配（config/exits.yaml）

| 规则 | 含义 | 默认配置 |
|------|------|----------|
| 止损 | 价格跌破成本 N% 自动卖出 | 双低 -15% / 双动量 -12% |
| 止盈 | 价格涨到成本 N% 自动卖出 | 双低 +30%（强赎前锁定） |
| 移动止损 | 从持仓最高点回撤 N% 自动卖出 | 双动量 10% |
| 时间止损 | 持有超过 N 天强制退出 | 默认关闭 |

引擎**每根K线自动检查**持仓，触发即执行清仓，并记录到交易流水。

## 三、参数要用回测校准（重要）

退出参数不是拍脑袋：刚做的回测显示，双动量加 10% 移动止损后，
回撤从 -22% 压到 -11.6%（✓ 风险下降），但年化从 22% 掉到 -3%（✗ 趋势利润被割掉）。
这说明**移动止损过紧会伤害趋势策略**——参数需要通过回测对比再定：

```bash
python3 scripts/engine_cli.py --strategy dual_momentum --mode backtest --trail 0.20
python3 scripts/engine_cli.py --strategy dual_momentum --mode backtest --trail 0.30
```

对比不同参数的收益/回撤后，把最优值写进 config/exits.yaml。

## 四、实盘执行（需要你提供券商账号）

纸面执行的同一套代码，接上真实券商即自动生效：

1. 在 `config/broker.yaml` 填写券商（QMT=A股可转债/股票、富途=港股美股、OKX=加密）
2. 运行 `python3 scripts/broker.py` 验证连接
3. 系统自动执行：调仓、止盈止损、风控、交易流水全自动

> 实盘前提（系统纪律）：模拟盘连续 3 个月跑赢基准 + 回测-模拟一致，否则不开通。
> 实盘前先用小资金（1-2 万）验证 1-2 个月，确认成交与模拟一致。
