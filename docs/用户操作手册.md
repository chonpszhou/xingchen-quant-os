# 星辰投研团 · 用户操作手册（小白版）

> 目标读者：没有编程基础的普通投资者。按本手册操作即可完成每日投研、信号跟踪与模拟盘查看。

---

## 一、这个系统是什么

一个帮你**自动盯盘、自动排名、自动预警、自动记账**的量化投研工具。它不替你按“感觉”交易，而是：

1. **每天收盘后**自动更新四市场（A股/港股/美股/加密）行情与基本面数据
2. **每天 16:00** 计算可转债“双低”排名（当前唯一通过严格验证的策略），并提示强赎/信用风险
3. **每 20 个交易日**自动模拟调仓一次，记录模拟盘净值（从 100 万虚拟本金开始）
4. **每周日**生成深度复盘摘要

系统内置一条铁律：**所有策略必须通过回测门控才能进入模拟盘，模拟盘连续达标才考虑实盘**。当前只有可转债双低策略通过了这道门。

## 二、快速开始（一次性设置，约 10 分钟）

### 第 1 步：安装环境（只需做一次）

在终端执行（需要 macOS，已安装 Python 3.11+）：

```bash
cd ~/Documents/ChatGPT/量化交易/星辰投研团
pip install -r requirements.txt
```

### 第 1.5 步：一键配置（推荐）

```bash
python3 scripts/setup_wizard.py
```

向导会引导你完成：推送凭证（可跳过）→ 实盘券商选择（可跳过）→ 每日自动运行安装 → 连接检查复检。全程约 5 分钟；不想交互就 `python3 scripts/setup_wizard.py --auto`（跳过凭证，自动装好每日运行）。

### 第 2 步：更新数据（首次约 20-40 分钟，之后每天 1-2 分钟）

```bash
python3 scripts/run_all.py update
```

### 第 3 步：跑一次完整链路

```bash
python3 scripts/run_all.py all
```

运行完会生成当日投研摘要：`docs/投研摘要_日期.md`，打开即可看到模拟盘净值、双低 TOP10、预警和期权波动率。

## 三、日常操作（每天 1 条命令）

每天收盘后（建议 16:30 之后）执行：

```bash
python3 scripts/run_all.py all
```

然后打开当天摘要文件看三件事：

| 看什么 | 怎么判断 |
|--------|----------|
| 模拟盘净值（双低/双动量/风险平价） | 双低预期年化 12-15%；双动量预期更高但波动更大；风险平价预期 6% 左右但回撤极小，三个都对照各自基准看超额 |
| 风控状态（摘要底部） | 回撤 >50% 阈值显示 ⚠ 警戒，>100% 阈值显示 🚨 超标（需按纪律暂停加仓）；连续 3 个月跑输基准 = 实盘门槛受挫 |
| 双低 TOP10 | 是否有新面孔；评级是否全部 A 级以上（出现 C/ST 说明过滤失效，需检查） |
| 预警栏 | ⚠ 开头的条目是必须处理的信号（强赎/信用风险） |

> 不需要每天看行情。系统替你盯，你只需看摘要和预警。

## 四、每周操作（每周日 1 条命令）

```bash
python3 scripts/run_all.py digest
```

周日复盘看三件事：

1. **模拟盘周净值变化**与双低组合换手（换手 >40% 说明市场风格切换，注意风险）
2. **港股/美股/加密监控**有没有触发异动（摘要中的 IV 快照与异动提醒）
3. **对照周报**：如果双低组合连续两周跑输全债基准，暂停新资金投入，观察两周

每月最后一天（或次月 1 号）额外执行一次：

```bash
python3 scripts/run_all.py monthly
```

生成 `docs/模拟盘月报_月份.md`：月收益、累计回撤、月度胜率、盈亏比，以及与回测预期（年化 12-15%、回撤≤20%、月胜率≥55%）的对照——**这是评估“能否转实盘”的核心文件**。

## 五、怎么读懂输出（新手必读）

### 双低排名表

`双低值 = 债券价格 + 转股溢价率`。值越低，代表“债券越便宜 + 转股也不贵”，历史上这类转债修复概率高。策略每月买排名前 20 的，等权持有。

### 模拟盘净值

`data/paper_cb_nav.parquet` 记录每天净值。**模拟盘是给实盘做体检的**：连续 3 个月跑赢“全债等权基准”且回撤可控，才考虑用真钱。

### 预警信号

- **价格 >130**：强赎风险，转债可能被提前赎回，持仓应卖出
- **正股 ST + 价格 <90**：信用风险，直接回避
- **VIX 2 年分位 >90%**：美股恐慌，减仓或买保护

## 六、开跑后 30 天会发生什么（预期日历）

如果你今天完成配置，接下来一个月大致是这样：

| 时间 | 会发生什么 | 你该做什么 |
|------|-----------|-----------|
| 第 1-2 天 | 模拟盘建仓完成，净值 ≈ 99.9 万（扣了首轮手续费） | 什么也不用做 |
| 第 3-19 天 | 三个模拟盘每天盯市，净值小幅波动（±1-2% 正常） | 每天瞄一眼摘要，**不要因为没赚钱而操作** |
| 第 ~21 天 | **首次调仓**：双动量/风险平价换仓、双低换一批转债 | 看摘要里的调仓说明，核对是否与规则一致 |
| 第 30 天 | 首份月度报告生成：三账户 vs 基准的超额 | 对照《读懂模拟盘报告》逐项看 |
| 第 60-90 天 | 第二次、第三次调仓与月报 | 连续 3 个月超额为正 → 准备小资金实盘验证 |

> 头一个月净值曲线“平淡”是正常的：双低是慢变量策略、风险平价追求低波动、双动量只在趋势明确时动。真正的信号是月度超额，不是日度波动。

## 七、纪律（比策略更重要）

1. **不追涨杀跌**：策略 20 个交易日才调仓一次，中间波动不操作
2. **不重仓单只**：永远 20 只等权，单只最大 5%
3. **预警必处理**：出现 ⚠ 先卖后问，不要等
4. **只用闲钱**：模拟盘转实盘前，先想清楚最大能承受的亏损（建议不超过总资产 20%）
5. **定期复查研究**：`docs/研究报告/` 里所有结论都是“当前数据下的诚实结果”，市场变了结论可能失效

> 系统每日自动运行风控监控（`scripts/risk_monitor.py`）：回撤阈值 双低 20% / 双动量 25% / 风险平价 10% / 组合 15%，
> 超标会自动出现在当日摘要的风控状态栏并触发预警——**规则由机器执行，不由情绪执行**。

## 八、常见问题

**Q：为什么只有可转债一个策略？**
A：系统对所有候选（价格因子、趋势、价值、股息等 13 份研究报告）统一回测，只有双低通过门控。宁缺毋滥。

**Q：数据会不会不准？**
A：免费数据源（腾讯/东财/BaoStock/CBOE/OKX）偶有延迟或限流，限流会自动重试；个别接口（美股个股期权链）被限流时会在报告中标注“待补”。

**Q：什么时候可以实盘？**
A：三个条件缺一不可——①模拟盘连续 3 个月跑赢基准；②回测与模拟表现一致（无“回测好看实盘打脸”）；③你已开通券商的可转债交易权限（A股账户即可）。

**Q：港股/美股/加密什么时候有策略？**
A：系统一直在验证，但目前没有通过门控的候选。在找到之前，这些市场只做监控，不做主动交易。
