# AAPL 灰度模拟 · 前向样本外验证报告（2026-09-02）

> 续十产出系统首个五道闸候选 **AAPL（美股）· `vol_target_momentum`**（样本外夏普 3.106 / 保留集 1.813 / DSR=1.0 / 回撤 −11.5%）。
> 按 SOP，候选通过五道闸后须进**前向样本外灰度模拟**验证，再论配置。本报告即该验证。

---

## 一、方法（严格无前视）

- 数据：`data/bars/美股/AAPL.parquet`，515 个交易日（2024-08-12 → 2026-08-31，日线）。扫描已用至 2026-08-31，无更新数据，故"前向"从现有序列切出**未参与训练/ holdout 的最近 63 个交易日**作为纯前向段。
- 切分：训练段 = 2024-08-12..2026-06-01（452 日）；**前向段 = 2026-06-02..2026-08-31（63 日）**。
- 参数选定：在训练段做小网格（window∈{126,189,252} / skip∈{10,21} / decay∈{0.03,0.05} / tvol∈{0.20,0.25,0.30}）按夏普选参，**不窥视前向段**。
- 信号：动量（12-1 月窗口 + 跳过 + 指数衰减）叠加波动目标仓位（权重 = min(1, 目标波动/实现波动)），t+1 收盘价成交；date t 的权重仅取决于 close≤t。
- 对照：同期 AAPL **买入持有（buy&hold）** 作为基准，防模拟假象。

## 三、解读

1. **候选未爆雷，前向成立 ✅**：在前向段（AAPL 横盘、B&H 仅 +0.5% 且 −12.7% 回撤）中，引擎已通过配置取得 **+4.6% / 夏普 0.89 / 同 −12.7% 回撤**——在震荡市保护了本金并跑赢 B&H 约 4 个百分点，波动目标仓位把回撤控制在与 B&H 相同水平。它不是"过闸即失效"的假候选。
2. **前向夏普显著低于引擎 holdout（1.813）**：引擎 holdout 是 **7 个 walk-forward 折的聚合**，跨多个 regime 平均偏高；本前向是**单一近期窗口（2026 年中横盘市）**，夏普天然更低（0.07–0.89）。属 regime 依赖，非失效。结论：AAPL 的期望前向夏普应取**更保守的 ~0.5–0.9**（震荡市），而非 holdout 的 1.8（含强势上涨 regime）。
3. **已通过配置比网格微调更稳**：训练段网格选出 w189，但应用到前向反而走平（−0.5%）；引擎默认/已通过配置（w252）前向 +4.6%。说明候选配置**未过拟合到训练 regime**，鲁棒性更好。
4. **纪律仍成立**：全程未动闸门阈值；灰度为"过闸后前向验证"，非二次过闸。

## 四、结论与建议

- **结论：FORWARD HOLDS ✅（带 regime 折价）**。AAPL 候选在真实未窥视的前向段未失效，震荡市保本+小幅跑赢，回撤受控。可进入下一步。
- **建议（待用户拍板）**：
  1. **建 `paper_aapl` 模拟账户**做**日频前向跟踪**（接入 launchd `run_all` 或独立 `gray_sim_account.py`），用最新数据持续累积前向样本，把"单窗口 63 日"扩成滚动验证。
  2. **配置量级**：若未来论配置，按保守前向夏普 ~0.5–0.9 定仓/定风险预算，不按 holdout 1.8 乐观值。
  3. **研究立场**：AAPL 研究视图为 neutral（共识 52），本候选纯量化驱动，无研究背书，更需灰度期观察。
- **风险**：单窗口 63 日样本小；美股单标的；若后续数据出现趋势反转，波动目标会快速降仓，回撤可控但收益弹性也受限。
