# 自动化定时分析任务 · 说明

> 完整参数见项目内 `config/tasks.yaml`

| 任务 | cron | 主要分析维度 | 触发推送条件 |
|------|------|-------------|-------------|
| 盘中异动监控 | `*/5 9-11,13-14 * * 1-5` | 见配置文件 | 「|涨跌幅| >= 5% 或 接近涨停/跌停」；「量比 >= 3」；「期权 IV 当日上升 >= 10%」 |
| 每日收盘速报 | `30 15 * * 1-5` | 自选股当日涨跌幅统计（按分组汇总）；成交量/量比异动 TOP10（A股、港股）；主力资金净流入 TOP10（A股，东方财富）；期权持仓量变化、IV 变化 TOP5（50ETF/30… | 定时推送 email+feishu |
| 每周深度复盘 | `0 20 * * 0` | 周涨跌幅 / 周成交量变化（自选股全量）；基本面：未来一周财报日历、业绩预告/快报、重要公告；期权：IV rank 与 IV 百分位（近1年）、期限结构、PCR 指标；资金面：两融… | 定时推送 email+feishu |
| 财报与基本面监控 | `0 9 * * 1-5` | 当日/未来3日财报日历（A股业绩预告、港股业绩期、美股财报）；营收同比变化率、归母净利同比变化率；毛利率/ROE 环比变化（财报发布后触发）；业绩预告方向：预增(>30%) / 预… | 「净利同比变化 > 30% 或 < -30%」；「财报发布日当天」 |
| 期权波动率日监控 | `0 16 * * 1-5` | IV rank / IV 百分位（近1年窗口）；隐含波动率(IV) vs 历史波动率(HV) 比值；期限结构斜率（近月 vs 远月）；平值IV与波动率指数（沪深300ETF波指 /… | 「IV 百分位 > 90%」；「IV/HV > 1.5」；「期限结构倒挂（近月IV > 远月IV）」 |
| 加密市场日监控 | `0 8,20 * * *` | 自选币 24h 涨跌幅、成交额变化；资金费率（永续合约，>0.05% 提示过热）；未平仓量变化（Deribit 期权 OI）；BTC 主导率与总市值变化 | 「24h 涨跌幅 > 10% 或 < -10%」；「资金费率 > 0.05%」 |
| 可转债双低策略监控 | `0 16 * * 1-5` | 双低值排名：价格≤130 且 转股溢价率≤50% 且上市满20日，双低=价格+溢价百分点，输出 TOP30；持仓异动：当前组合（前20）价格突破 130（强赎风险）或溢价率跳升 >… | 「持仓价格突破 130 或溢价跳升 > 10pp」；「持仓出现信用风险（<90 且正股 ST）」；「双低组合周度换手 > 40%」 |
| 美股波动率指数监控 | `0 22 * * 1-5` | VIX / VXN / VXD 最新值及 2 年分位（CBOE 官方 CSV）；指数 ETF（SPY/QQQ/DIA）20 日实现波动率分位与 IV/RV 比；个股期权链 ATM … | 「VIX 2年分位 > 90%」；「IV/RV > 1.3 或 < 0.8」 |

## 落地方式

- **cron**：直接使用各任务 cron 表达式
- **APScheduler**：`pip install apscheduler`，由调度器读取 tasks.yaml
- **Codex 定时提醒**：可在 Codex 应用内创建
