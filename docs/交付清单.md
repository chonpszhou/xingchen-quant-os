## 四、验证方式（复现路径）

```bash
git clone git@github.com:chonpszhou/xingchen-quant-os.git
pip install -r requirements.txt
python3 scripts/check_connections.py    # 26 项连接检查
python3 scripts/run_all.py all          # 全链路（数据→信号→三模拟盘→摘要）
python3 scripts/system_status.py        # 健康看板
python3 scripts/acceptance_test.py      # 一键验收（7 项全绿）
```

> 数据缓存（data/）不入库，首次运行 `run_all.py update` 自动重建（约 30-60 分钟）。
