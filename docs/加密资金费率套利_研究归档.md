# 加密资金费率套利（Funding Carry）· 研究归档

> 归档日期：2026-08-11 · 状态：暂缓（数据受限 + 风险不适配）

## 思路

永续合约资金费率：多空方向持仓者定期互换资金，正费率时空头收钱。
理论上可做“正费率时收资金”的套利（空永续 + 多现货对冲价格风险），是加密专属的
documented edge 之一，也正好填补“数字货币市场无策略”的空白。

## 验证受阻（数据层）

免费资金费率历史源的深度全部受限：

| 来源 | 结果 |
|------|------|
| OKX funding-rate-history | 公开接口仅返回最近 ~100 条（约 33 天），分页参数不生效 |
| Bybit funding/history | 本网络返回非 JSON（区域拦截） |
| Gate futures funding_rate | 需鉴权（401） |
| Deribit get_funding_rate_value_history | 返回为空/字段不稳定（interest 与 premium 拆分） |

缺少多年历史费率，无法做可靠回测；勉强用 30 天数据会得出无统计意义的结论，违反项目纪律。

## 风险不适配

即使数据解决，策略也要求：永续合约（杠杆）、保证金管理、对资金费率时点的高度敏感——
不符合“面向普通金融小白”的定位，实盘执行错误成本高。

## 结论与替代

- **暂缓**：待有可靠费率历史数据源（或 Tushare 加密数据）后再评估
- 数字货币市场的日常监控（行情/费率快照/异动）已接入系统；费率快照每日记录，未来数据
  齐备时可回填研究

> 本归档基于公开数据与规则化分析生成，仅供学习研究参考，不构成投资建议。
